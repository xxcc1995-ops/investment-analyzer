## 八大战法界面重做 + 「应用策略无结果」根因修复

用户反馈旧的 CbEightStrategies 内联卡片太丑、点「应用策略」筛选结果不显示。

### 根因（关键 bug）
- `_fetch_akshare_cb` 把 `year_left`/`volume`/`amount` 硬编码为 `''`，`_normalize_cb` 转成 0。
- 所有 filter 含 `year_left >= 1` / `turnover >= X` / `ytm_rt > 0` 条件 → 在 AKShare 兜底路径下全部被排除 → `total=0`，表现为「应用策略无结果」。
- 即使用户集思录未登录、走 AKShare 兜底，也会看不到任何标的。

### 修复（cb_service.py）
- 新增模块级容错辅助：`_UNKNOWN=-1.0`、`_known_ge(val,thr)`、`_known_range(val,lo,hi)`、`_known_gt(val,thr)`：未知哨兵（year_left/turnover=-1，ytm=-999.9）时视为「通过、不因此排除」。
- `get_master_strategy`：非 jisilu 数据源时，把每只 bond 的 `year_left/turnover` 置 -1、`ytm_rt` 置 -999.9（标记未知）。
- 全部 11 个 filter 的 year_left/turnover 条件改用 `_known_ge/_known_range`；revision_game 的 `ytm_rt > -2` 改用 `_known_gt`（否则 -999.9 被误杀）。
- 归一化排除条件新增 `'退' not in bond_nm`（剔除退债/退市的违约债，如 汇车退债/搜特退债，akshare 噪声导致双低异常低）。
- ytm_defense 仍严格 `ytm_rt > 0` → AKShare 无 YTM 时返回空（前端提示需登录集思录）。

### 新界面（替换丑卡片）
- 删除 `components/CbEightStrategies.tsx` 及 `pages.css` 的 .cb-eight-* 块。
- 新增 `pages/CbStrategiesPage.tsx`：Ant Design 主从布局——左侧 8 战法列表（图标+风险色），右侧详情（philosophy Tags + Tabs：筛选结果表/战法详解/横向对比）；选战法自动运行，结果用 antd Table 展示（双低值颜色分级、质量评级徽章、YTM/剩余年限未知显示「—」）。
