# REIT高分红筛选器设计文档

## 概述

设计一个专注于中国公募REITs的高分红筛选器，帮助投资者识别分红率5%以上的优质REIT，同时规避常见投资陷阱。

## 目标用户

个人投资者，追求稳定分红收入，希望系统化筛选REIT投资标的。

## 核心功能

1. **多维度筛选**：现金分派率、P/NAV、出租率、负债率、流动性
2. **风险提示**：自动标注各类REIT的潜在风险
3. **评分系统**：综合评分帮助快速识别优质标的

## 筛选指标体系

| 指标 | 权重 | 筛选标准 | 说明 |
|-----|------|---------|------|
| 现金分派率 | 35% | ≥5% | 最近12个月实际分红/当前价格 |
| P/NAV | 25% | <1.2 | 价格/净资产价值，越低越好 |
| 出租率 | 20% | >85% | 底层资产实际运营情况 |
| 资产负债率 | 10% | <50% | 财务健康度 |
| 日均成交额 | 10% | >100万 | 流动性保障 |

## REIT投资踩坑点

### 1. 分红率幻觉
- 风险：高分红可能包含本金返还
- 应对：区分"现金分派率"和"可供分配金额"

### 2. 溢价炒作
- 风险：二级市场价格远高于净值
- 应对：筛选P/NAV < 1.2

### 3. 流动性陷阱
- 风险：日成交量极低，难以卖出
- 应对：筛选日均成交额 > 100万

### 4. 出租率下降
- 风险：底层资产运营恶化
- 应对：筛选出租率 > 85%

### 5. 负债过高
- 风险：财务风险大
- 应对：筛选资产负债率 < 50%

### 6. 解禁压力
- 风险：战略配售份额解禁后集中抛售
- 应对：提示解禁时间

### 7. 利率风险
- 风险：利率上行压制估值
- 应对：提示利率环境

## 底层资产分类

| 类型 | 特点 | 风险等级 |
|-----|------|---------|
| 产业园区 | 稳定，受经济周期影响 | 中 |
| 高速公路 | 现金流好，但有期限 | 中低 |
| 仓储物流 | 需求稳定，电商驱动 | 低 |
| 保障性租赁住房 | 政策支持，波动小 | 低 |
| 能源基础设施 | 分红高，但受政策影响 | 中 |
| 商业/消费 | 新品种，样本少 | 中高 |

- **实时数据**：东方财富API（价格、成交额）

- **估值数据**：P/NAV需要计算（价格/单位净值）

## 评分算法

```python
def calculate_reit_score(reit: dict) -> int:
    score = 0

    # 现金分派率 (35分)
    dividend_yield = reit.get("dividend_yield", 0)
    if dividend_yield >= 8:
        score += 35
    elif dividend_yield >= 6:
        score += 28
    elif dividend_yield >= 5:
        score += 21

    # P/NAV (25分)
    p_nav = reit.get("p_nav", 999)
    if p_nav <= 0.8:
        score += 25
    elif p_nav <= 1.0:
        score += 20
    elif p_nav <= 1.2:
        score += 12

    # 出租率 (20分)
    occupancy = reit.get("occupancy_rate", 0)
    if occupancy >= 95:
        score += 20
    elif occupancy >= 90:
        score += 16
    elif occupancy >= 85:
        score += 10

    # 资产负债率 (10分)
    debt_ratio = reit.get("debt_ratio", 100)
    if debt_ratio <= 30:
        score += 10
    elif debt_ratio <= 40:
        score += 8
    elif debt_ratio <= 50:
        score += 5

    # 流动性 (10分)
    daily_turnover = reit.get("daily_turnover", 0)
    if daily_turnover >= 500:
        score += 10
    elif daily_turnover >= 200:
        score += 8
    elif daily_turnover >= 100:
        score += 5

    return score
```

## 设计决策

- 选择方案B（标准版）：平衡功能完整性和实现复杂度
- 最低分红率5%：用户明确要求
- P/NAV上限1.2：避免溢价过高
- 出租率下限85%：确保资产运营健康
