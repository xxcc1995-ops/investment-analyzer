# 币圈投资信息收集工具设计文档

## 概述

设计一个币圈投资信息收集工具，帮助投资者筛选主流交易所上的靠谱项目，过滤垃圾信息，只保留精华。

## 目标用户

个人投资者，想要系统化了解币圈市场，避免踩坑空气币。

## 核心功能

1. **项目筛选**：多维度评分筛选靠谱项目
2. **新币监控**：近期上线的潜力项目
3. **项目详情**：查看项目背景、团队、投资机构等

## "靠谱"项目定义（评分体系）

| 维度 | 权重 | 靠谱标准 | 说明 |
|-----|------|---------|------|
| 市值排名 | 25% | 前200名 | 避免小市值空气币 |
| 流动性 | 20% | 24h交易量>500万USD | 确保能买卖 |
| 上线时间 | 15% | >30天 | 避免新币炒作 |
| 社区活跃 | 15% | Twitter粉丝>5万 | 有真实社区 |
| 代码更新 | 15% | GitHub提交>10次/月 | 项目在持续开发 |
| 项目背景 | 10% | 有知名机构投资 | 背书可信度 |

## 信息筛选标准

### 过滤掉的"垃圾信息"
- 市值排名>500的小币
- 24h交易量<100万USD
- 上线<7天的新币
- 无官方网站或白皮书
- 社区粉丝<1万
- 代码仓库无更新>6个月

### 保留的"精华信息"
- 市值前200的主流币
- 有知名机构投资的项目
- 代码持续更新的项目
- 社区活跃度高的项目
- 近期有重大进展的项目

## 数据源

| 数据类型 | 数据源 | API | 限制 |
|---------|--------|-----|------|
| 市值/价格 | CoinGecko | `/coins/markets` | 10-30次/分钟 |
| 新币上线 | CoinGecko | `/coins/list` | 免费 |
| GitHub数据 | GitHub API | `/repos/{owner}/{repo}` | 60次/小时 |
| 项目信息 | CoinGecko | `/coins/{id}` | 免费 |

## 评分算法

```python
def calculate_crypto_score(coin: dict) -> int:
    score = 0
    
    # 市值排名 (25分)
    rank = coin.get("market_cap_rank", 999)
    if rank <= 10:
        score += 25
    elif rank <= 50:
        score += 20
    elif rank <= 100:
        score += 15
    elif rank <= 200:
        score += 10
    
    # 流动性 (20分)
    volume = coin.get("total_volume", 0)
    if volume >= 1000000000:  # 10亿
        score += 20
    elif volume >= 500000000:  # 5亿
        score += 16
    elif volume >= 100000000:  # 1亿
        score += 12
    elif volume >= 50000000:  # 5000万
        score += 8
    
    # 上线时间 (15分)
    age = coin.get("age_days", 0)
    if age >= 365:  # 1年以上
        score += 15
    elif age >= 180:  # 6个月
        score += 12
    elif age >= 90:  # 3个月
        score += 8
    elif age >= 30:  # 1个月
        score += 5
    
    # 社区活跃 (15分)
    twitter = coin.get("twitter_followers", 0)
    if twitter >= 1000000:
        score += 15
    elif twitter >= 100000:
        score += 12
    elif twitter >= 50000:
        score += 8
    elif twitter >= 10000:
        score += 5
    
    # 代码更新 (15分)
    commits = coin.get("github_commits_month", 0)
    if commits >= 50:
        score += 15
    elif commits >= 20:
        score += 12
    elif commits >= 10:
        score += 8
    elif commits >= 5:
        score += 5
    
    # 项目背景 (10分)
    if coin.get("has_institutional_investors"):
        score += 10
    elif coin.get("has_known_team"):
        score += 7
    
    return score
```

## 设计决策

- 选择方案B（标准版）：平衡功能完整性和实现复杂度
- 使用CoinGecko免费API：无需API Key，适合个人使用
- 多维度评分：避免单一指标导致的误判
- 信息筛选：过滤垃圾信息，只保留精华
