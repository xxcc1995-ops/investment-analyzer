私人投资分析工具，模仿理杏仁，用于基本面分析、估值计算和宏观数据跟踪。

## 功能

### 股票分析
- 基本面指标查询：PE、PB、ROE、营收增长率、净利润增长率
- DCF估值模型：自由现金流折现计算买点
- 巴菲特选股逻辑分析

### 筛选工具
- **攒股收息** - 王文/散户乙策略，高分红低估值
- **捡烟蒂** - 港股烟蒂股筛选
- **价投筛选** - 巴菲特/芒格/李录/段永平体系
- **REIT筛选** - 高分红REIT
- **机哥体系** - 金渐成投资体系（第一兼唯一选股法）
- **出口冠军** - 全球竞争力、分红稳健、行业龙头筛选

### 套利工具
- 基金套利（LOF折溢价监控）
- 可转债双低轮动策略
- 期权年化收益计算器
- **期权轮动策略** - 卖期权评分、BSM定价、轮动推荐
- **网格交易** - 自动网格、历史回测、仓位管理

### 宏观数据
- **中国核心指标**：GDP、CPI、PPI、PMI（官方+财新）、M2、LPR、社融、工业增加值、贸易差额、外储、新增信贷
- **美国核心指标**：GDP、CPI、PPI、ISM制造业/服务业PMI、非农就业、美联储利率、零售销售、失业率
- **收益率曲线**：中美2Y/5Y/10Y/30Y国债收益率 + 2Y-10Y利差（衰退预测指标）
- **消费拐点指标**：消费者信心指数、PPI、社零、房价、失业率
- **信号仪表盘**：6个宏观信号（衰退风险/降息概率/复苏强度/通胀/流动性/曲线）+ 8类资产配置建议
- **数据质量层**：每条数据标记来源(FRED/统计局/央行)、置信度、时效性；官方PMI vs 财新PMI交叉验证
- 期货商品快照、行业排名、资金流向

## 消费拐点指标说明

### 消费者信心指数
国家统计局编制，基于全国约4万户城镇居民抽样问卷（月度）。

问卷两个维度：
- **满意指数**：对当前家庭收入、经济形势的评价
- **预期指数**：对未来6个月收入变化、经济形势、购买时机的预期

计算公式：
```
选项赋分：非常满意=100, 满意=75, 一般=50, 不满意=25, 非常不满意=0
满意指数 = 各选项加权平均
预期指数 = 各选项加权平均
消费者信心指数 = (满意指数 + 预期指数) / 2
```

参考值：2019年(疫情前)约127, 2022年(低点)约86, 100以上为乐观区间。

### PPI（工业品出厂价格指数）
以2020年为基期（=100），抽样调查全国约4万家工业企业，涵盖40个工业行业大类、约1300个基本分类的代表产品。

```
指数 > 100: 工业品价格上涨（通胀）
指数 = 100: 价格持平
指数 < 100: 工业品价格下跌（通缩）
```

### 社会消费品零售总额（社零）
统计范围：商品零售 + 餐饮收入。国家统计局对限额以上企业全面调查 + 限额以下抽样调查。

### 70城新建住宅价格指数
国家统计局每月发布70个大中城市住宅销售价格变动情况。同比指数以去年同月为100。

### 城镇调查失业率
国家统计局月度调查，统计城镇常住人口中16岁以上、有劳动能力、正在寻找工作但未就业的人员占比。

## 微信公众号日报

通过微信读书 API 自动抓取关注的公众号文章，AI 生成每日摘要日报。

- **侧边栏入口：** 行情总览 → 公众号日报
- **功能：** 扫码登录 → 同步文章 → AI 摘要 → 按公众号分组展示
- **技术：** Python 后端 (httpx + BeautifulSoup) + React 前端

## 技术栈

- 前端：React + TypeScript + ECharts + Vite
- 后端：Python FastAPI + AKShare
- 数据源：新浪财经（行情）、东方财富（财务）、AKShare（宏观/指数/期货/REIT）、集思录（基金套利/可转债）、Polymarket（预测市场）、雪球（大V持仓）
- 微信公众号：Node.js + Cheerio（文章抓取与日报生成）

## 快速开始

### 后端

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8002
```

### 前端

```bash
cd frontend
npm install
npx vite --port 5173
```

- 前端：http://localhost:5173
- 后端API：http://localhost:8002
