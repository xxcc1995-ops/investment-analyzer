# Investment Analyzer - 投资分析工具

私人投资分析工具，模仿理杏仁，用于基本面分析、估值计算和宏观数据跟踪。

## 功能

### 股票分析
- 基本面指标查询：PE、PB、ROE、营收增长率、净利润增长率
- DCF估值模型：自由现金流折现计算买点
- 巴菲特选股逻辑分析

### 筛选工具
- **攒股收息** - 王文/散户乙策略，高分红低估值
- **捡烟蒂** - 港股烟蒂股筛选
- **价投筛选** - 巴菲特/芒格/李录/段永平体系
- **REIT筛选** - 高分红REIT
- **机哥体系** - 金渐成投资体系（第一兼唯一选股法）
- **出口冠军** - 全球竞争力、分红稳健、行业龙头筛选

### 套利工具
- 基金套利（LOF折溢价监控）
- 可转债双低轮动策略
- 期权年化收益计算器
- **期权轮动策略** - 卖期权评分、BSM定价、轮动推荐
- **网格交易** - 自动网格、历史回测、仓位管理

### 宏观数据
- 核心指标：GDP、CPI、PMI、M2、LPR、社融
- **消费拐点指标**（详见下方）：消费者信心指数、PPI、社零、房价、失业率
- 美国CPI、失业率
- 期货商品快照、行业排名、资金流向

### Polymarket 分析
- 套利检测、价值发现、趋势追踪
- Kelly仓位计算器

### 雪球大V
- 鹿鼎公、管我财、小卡叔等大V持仓跟踪

## 消费拐点指标说明

### 消费者信心指数
国家统计局编制，基于全国约4万户城镇居民抽样问卷（月度）。

问卷两个维度：
- **满意指数**：对当前家庭收入、经济形势的评价
- **预期指数**：对未来6个月收入变化、经济形势、购买时机的预期

计算公式：
```
选项赋分：非常满意=100, 满意=75, 一般=50, 不满意=25, 非常不满意=0
满意指数 = 各选项加权平均
预期指数 = 各选项加权平均
消费者信心指数 = (满意指数 + 预期指数) / 2
```

参考值：2019年(疫情前)约127, 2022年(低点)约86, 100以上为乐观区间。

### PPI（工业品出厂价格指数）
以2020年为基期（=100），抽样调查全国约4万家工业企业，涵盖40个工业行业大类、约1300个基本分类的代表产品。

```
指数 > 100: 工业品价格上涨（通胀）
指数 = 100: 价格持平
指数 < 100: 工业品价格下跌（通缩）
```

### 社会消费品零售总额（社零）
统计范围：商品零售 + 餐饮收入。国家统计局对限额以上企业全面调查 + 限额以下抽样调查。

### 70城新建住宅价格指数
国家统计局每月发布70个大中城市住宅销售价格变动情况。同比指数以去年同月为100。

### 城镇调查失业率
国家统计局月度调查，统计城镇常住人口中16岁以上、有劳动能力、正在寻找工作但未就业的人员占比。

### 拐点信号值
| 指标 | 当前参考 | 拐点信号 |
|------|---------|---------|
| 消费者信心 | 90 | > 100 |
| PPI | 102.8 | 持续 > 100 |
| 社零增速 | +0.2% | > 3% |
| 房价同比(一线) | +0.7% | > 0% |
| 失业率 | 5.2% | < 5% |

## 技术栈

- 前端：React + TypeScript + ECharts + Vite
- 后端：Python FastAPI + AKShare
- 数据源：新浪财经（行情）、东方财富（财务）、AKShare（宏观/指数/期货/REIT）、集思录（基金套利/可转债）、Polymarket（预测市场）、雪球（大V持仓）

## 快速开始

### 后端

```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --port 8001
```

### 前端

```bash
cd frontend
npm install
npx vite --port 5173
```

- 前端：http://localhost:5173
- 后端API：http://localhost:8001
