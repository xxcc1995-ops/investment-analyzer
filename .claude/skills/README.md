# Claude Code Skills

本项目包含以下 Claude Code 技能：

| 技能 | 说明 |
|------|------|
| aihot | AI 热点分析 |
| hv-analysis | 横纵分析法深度研究 |
| khazix-writer | 公众号写作 |
| neat-freak | 文档同步整理 |

## 安装方法

### Windows
```cmd
.claude\install-skills.bat
```

### Mac/Linux
```bash
bash .claude/install-skills.sh
```

安装后重启 Claude Code 即可使用。
